This repository contains the files to compute HF and MP2 energies in C.
    -LICENSE: file specifying the license for our code.
    -AUTHORS: file listing the names of all contributors.
    -INSTALL.md: file with instructions on how to compile and run the program.
    -refman.pdf: documentation generated with doxygen.
    -test: directory containing tests to proof that the program behaves as expected. .h5 files are the TREXIO data files and .out are the output files of the program.
    -src: directory containing all the source files of the program
